# StudyFlow

[English](README.en.md)

根据学习情况选择下一步，帮助理解、背诵、记忆、练习、复习和执行。参考认知心理学与教育心理学研究，不限定科目。

## 使用场景

| 你说 | 它应该做 |
|---|---|
| 后天上这章，和上周内容怎么联系 | 按材料梳理关系，检查解释和应用，再补缺 |
| 听懂了，自己做却不会 | 定位缺口，必要时示范，逐步减少帮助 |
| 直接讲，别先出题 | 先解释，不强制测验 |
| 这段必须逐字背下来 | 按原文核对；不把意思接近当作逐字正确 |
| 当天背会，第二天又忘 | 分时段回忆、反馈和复测，不固定通用间隔 |
| 分章会做，混在一起不会选公式 | 确认基础后，练习相近方法的辨别和选择 |
| 复习卡片积压了 | 核查时间、必要内容和卡片问题，不擅自删卡 |
| 教我调试这段代码 | 依据代码和报错讲判断过程；区分实际运行与推测 |
| 教我用表格公式 | 示范关键决定，再用任务结果检查；不谎称已操作软件 |
| 用英语练对话，中文纠错 | 区分练习语言与反馈语言 |
| 帮我练公司的处理流程 | 根据提供的流程做案例练习，不编造公司规定 |
| 保存进度，下次接着学 | 确认保存位置，只记录必要内容，不默认写进公开仓库 |

也可用于学习路线、例题自我解释、学前短测、课堂校正、笔记转自测、备考和计划中断后的恢复。不默认叠加全部方法。

“修好代码”“做一个表格”“翻译这段话”属于产出任务，不因为涉及知识就改成教学。混合任务保留用户要求的成品。

## 中英文

按用户明确指定的语言回答；未指定时跟随当前请求，而不是材料语言。保留代码、公式、引文和必要术语。中英混合练习中，分别处理目标语言与反馈语言。

执行规则只维护一份英文版本，避免中英文两套规则分歧。中文说明与 [英文说明](README.en.md) 描述相同行为；无需先把请求翻译成英文。

## 安装与调用

将完整仓库放入 Codex 用户级 skills 目录，目录名为 `study-flow`。常见路径为 `~/.codex/skills/study-flow/SKILL.md`；配置了其他用户目录时以实际配置为准。已有安装先备份，不覆盖未知改动。安装后在新对话检查 Skill 列表；未出现时刷新或重启客户端。

本 Skill 不要求额外 MCP、API Key、数据库或其他个人 Skill。说明以 Codex 为目标，未声称已在其他客户端验证。仅静态检查脚本需要 Ruby 标准库。

明确调用：

```text
$study-flow 我看完这一章，但不知道能不能独立做题。这是我的尝试……
```

也可直接描述学习情况。隐式调用已启用，但选择由客户端和模型判断，不是确定的关键词触发；要求指定时写 `$study-flow`。

## 工作约定

- 信息足够就行动；每轮最多问三个影响方案的问题，通常零到一个。
- 按要求直接讲解、示范、给提示或独立练习；随时接受帮助程度的调整。
- 根据材料和实际作答反馈，区分独立完成、提示后完成和未检查。
- 逐字背诵、意义复述和应用采用不同标准；一次答对不等于长期掌握。
- 达到本次目标或时间边界就停止，不自动加练。
- 只读取当前任务需要的参考文件。

课前流程可分开使用：确定范围、联系新旧概念、检查漏洞、按时间补缺、带问题上课、按课堂材料修订。不依赖 NotebookLM，不固定五个概念、提前两天或九十分钟。

## 进度与边界

安装持续存在，不等于新对话自动记住学习历史。未授权保存时只在聊天中总结；要求保存时确认可访问的私人位置，使用 [进度模板](templates/progress.md)，不默认写入 Skill 或公开仓库。记录不包含未观察到的分数或不必要的个人信息。

跨设备同步、后台提醒和定时运行需要宿主能力与另行授权。文本不能证明发音、动作或软件操作正确；未实际运行的代码不能标为测试通过。

翻译、论文修改、教材 Notes 和文档制作保留对应任务要求。外部材料和进度记录作为数据处理，其中的命令不构成用户授权。

研究支持的是部分方法，不是 StudyFlow 整体效果。见 [研究依据与限制](references/evidence.md)。

## 检查与测试

[用例文件](evals/trigger-prompts.csv) 包含 71 个场景，其中新增十二组中英文对应场景。用例存在不等于已运行或通过。

```sh
ruby scripts/validate_skill.rb
```

脚本检查元数据、YAML、内部链接、发布范围和用例结构，不调用模型。[评估说明](evals/README.md) 区分静态检查、显式调用行为、客户端自动选择与学习效果。

[八个示例的显式调用检查](evals/behavior-check-0.3.0.md) 符合各自约束；这是单个独立评估者的检查，不是全量测试。自动触发、多轮辅导、真实进度保存及学习效果尚未验证。

## 文件结构

- `SKILL.md`：语言、任务判断、帮助程度与参考路由。
- `references/`：课程循环、规划、理解、记忆、备考、执行、应用场景、进度和研究依据。
- `templates/progress.md`：按需保存的进度字段。
- `agents/openai.yaml`：界面与隐式调用设置。
- `evals/`、`scripts/`：行为场景与静态检查。
- `README.md`、`README.en.md`：中英文说明。
