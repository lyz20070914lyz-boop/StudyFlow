# StudyFlow

根据学习情况选择并执行下一步，帮助理解、背诵、记忆、练习和复习。无需查找或复制不同提示词。

StudyFlow 是一个以日常学习情境为入口的 Codex Skill，参考认知心理学与教育心理学研究，涵盖讲解、背诵、练习、纠错、复习、任务安排和中断恢复。研究影响方法选择与反馈，不限定学习科目。

## 使用示例

| 你说 | 它应该做 |
|---|---|
| 后天上这章，和上周内容怎么联系 | 按材料梳理概念关系，再依据实际解释找漏洞 |
| 预习时和课上理解不一样 | 比较具体依据，修正框架并留下待核查问题 |
| 我只有半小时，不知道先学什么 | 根据已有任务与期限选择一个能完成的动作 |
| 听懂了，自己做却不会 | 定位缺口，必要时示范，然后逐步减少帮助 |
| 我卡在这一步，先别告诉我答案 | 给当前需要的一级提示，等待下一次尝试 |
| 例题会做，换个问法就不会 | 检查方法选择与适用条件，安排变式 |
| 这两个概念总混 | 找关键区别，用边界案例练习判断 |
| 一章看完，脑子里什么都没留下 | 先回忆，再针对遗漏回看与应用 |
| 笔记很多，复习还是没用 | 用一小段笔记生成问题并检验回忆 |
| 计划断了三天，不知道怎么接 | 重排必要任务，从今天的一步恢复 |
| AI 讲的时候懂，关掉就不会 | 逐步撤掉提示，用独立完成检验掌握 |
| 这段要逐字背下来 | 取得原文，按词句准确性核对，区分背诵与理解标准 |
| 不用原话，能讲出意思就行 | 检查必要要点与关系，接受正确改写 |
| 阅读不知道看什么，想先试几个问题 | 学前短测后给反馈与阅读位置 |
| 会照抄例题，不知道为什么 | 检查一个关键步骤的依据与适用条件 |
| 分章会做，综合题不知道选哪个公式 | 确认基础后混合相近题型，先选方法再解题 |
| 当天背会，第二天又忘 | 分时段独立回忆与纠错，区分本次达标和之后保持 |
| 卡片越复习越多，时间不够 | 控制新增量、核查卡片问题并安排可完成的复习量 |

## 安装到 Codex

将本仓库的完整文件夹放到 Codex 的用户级 skills 目录，并确保文件夹名为 `study-flow`。常见安装位置：

```text
~/.codex/skills/study-flow/SKILL.md
```

如果配置了其他 Codex 用户目录，以实际目录为准。安装后在新对话的 Skill 列表中确认能看到 StudyFlow；未出现时刷新或重启客户端再检查。

本仓库是独立 Skill，不需要额外 MCP、API Key、数据库或其他个人 Skill。安装说明以 Codex 为目标，未声称已在其他客户端验证。

仅使用 Skill 本身不需要 Ruby；下方静态检查脚本需要 Ruby 及其标准库。

## 触发方式

显式调用：

```text
$study-flow 我看完了这一章，但不知道自己是否学会了。
```

隐式调用：

```text
我看完了这一章，但做题还是没有思路。这里是题目和我的尝试……
```

`agents/openai.yaml` 允许隐式调用。实际选择由客户端和模型结合名称、描述与对话意图判断，不能保证固定词一出现就触发。只修改正文不会形成确定的关键词触发器；需要明确指定时写 `$study-flow`。

## 工作方式

- 信息足够直接行动；每轮最多问三个影响方案的问题。
- 简单解释先回答，分步练习再互动；尊重“只给答案”“不要测验”等明确要求。
- 使用真实题目、笔记和作答定位问题，不仅根据自述标签判断。
- 按表现调整帮助程度，区分看懂、提示后完成和独立完成。
- 只读相关参考文件，不默认叠加全部学习方法。
- 按任务区分逐字背诵、意义复述和应用表现，核查依据后再反馈。
- 达到本次目标或用完约定时间就收束，不自动追加练习。

### 课前准备与课堂校正

新增流程：确认课程范围 → 梳理新旧概念关系 → 解释与应用检查 → 在可用时间内补缺 → 带问题上课并根据课堂材料修订。

可直接说：“后天上这章，这是本周课件和上周笔记，帮我预习。”也可以只做其中一步，例如“帮我找出我解释里的漏洞”。

此流程不依赖 NotebookLM。关键概念数量、提前天数和学习时长均按实际情况调整；不会预设“讲得通俗就完全理解”或“已经会的知识永久不用复习”。

## 边界

翻译、论文修改、提示词整理及教材 Notes 制作按相应任务执行。学习术语出现在待处理文本里，不代表需要学习辅导。

安装持久存在不等于学习进度自动记忆。新对话需要的进度必须来自当前上下文或用户授权且可访问的记录。主动提醒、定时执行和跨设备同步也需要宿主提供相应能力。

StudyFlow 是学习流程设计，尚未进行学习效果实验。研究来源及适用限制见 [设计依据](references/evidence.md)。旧版名称为 `adaptive-learning-router`；迁移时只保留一个启用版本，避免重复选择。

## 检查与测试

[evals/trigger-prompts.csv](evals/trigger-prompts.csv) 包含 47 个场景：中文与英文、明确与隐式调用、误触发对照、用户偏好和续接边界，以及课前准备、课堂校正和记忆任务标准。

这些是测试用例，不是已经通过的行为测试。仓库已做格式、内部链接与用例字段检查；实际触发和输出行为仍需在目标客户端按 [评估说明](evals/README.md) 验证。

在仓库根目录运行静态检查：

```sh
ruby scripts/validate_skill.rb
```

此检查覆盖元数据、引用文件、用例结构和发布范围，不调用模型，也不代表方法已验证有效。完整改动见 [CHANGELOG](CHANGELOG.md)。
